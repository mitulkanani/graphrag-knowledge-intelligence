# Platform Architecture Notes

The Atlas Platform stores shipment events and exposes an API for partner systems. Beacon Analytics consumes curated shipment data from the Atlas Platform. Helios Systems operates the monitoring service that observes delivery exceptions. Northstar Logistics sends delivery updates to Helios Systems.

Acme Robotics owns the warehouse robot fleet. The robot fleet sends status events to the Atlas Platform. Beacon Analytics helps operations teams understand delivery performance across regions.
